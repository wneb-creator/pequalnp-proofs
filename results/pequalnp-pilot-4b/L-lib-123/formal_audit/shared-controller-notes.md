# Additional universal-route tests

These are analyses of proposed methods, not a proof or a refutation of FP3.

**Independent per-stack replay.** A bounded-height joint visit can alternate between several mutable blocks arbitrarily often. Per-stack local replays then require shared read/control messages at every such interaction. Recording only entry/exit controllers leaves the other blocks' supplied values unbound. Grouping all active blocks into one replay restores soundness, but a generic joint boundary contains a full block word. The usual costs are either many inter-stack messages or many full boundary words.

**A one-writable-tape active cache.** Keeping several active chunks near the writable head does not make a cold-block exchange cost only the distance to storage. Moving a b-symbol chunk across distance S with one writable head generally requires b*S transport work. An O(S) exchange charge tacitly uses another writable buffer or an unverified guessed copy. A nondeterministically guessed copy still requires an exact binding equality check. This is an obstruction to that construction, not a lower bound on all simulations. Separate read-only input heads also mean that ordinary single-tape palindrome arguments do not automatically apply to the paper's model.

**Nested deterministic checking.** The relevant generic deterministic budget is (U*S^2)^(1/3), not merely sqrt(U*S). Thus space T^(1/2) permits an original-time saving whenever the accompanying simulation time is below T^2 by a fixed power. The displayed tree-evaluation routes still have no such bound. The independently checked NestedCheckpoints theorem establishes the E/A/E quantifier pattern, including zero-length cases. A generic nondeterministic simulation cannot automatically use this deterministic dual check; its choices must be fixed or otherwise made compatible with the same quantifier pattern.

**Universal fingerprints.** The union bound in UniversalFingerprint correctly handles adaptive final witnesses when there is a fixed finite structural certificate family and each false certificate has few accepting seeds. Error polynomials must be independent of the challenged seed once the structural certificate is fixed. Deterministically forced field-arithmetic auxiliaries need not be counted as independent choices; freely guessed field values do. A full B-bit local transcript ordinarily needs at least about B seed bits for the union bound, so storing those hashes at T/B boundaries costs order T. A smaller honest structural certificate family remains a separate obligation.

Short input does not bound the number of illegal relaxed traces by the number of real computations. A fixed program can push a long all-zero word and then pop it, recording whether any popped bit is one. The real result is false, but a relaxed verifier that guesses pop symbols has exponentially many illegal words. In characteristic two, the challenged extension-field element's minimal polynomial supplies a nonzero short binary word hashing to zero when the word length exceeds the extension degree. This only defeats that relaxed fingerprint scheme: the underlying example language is trivial.

**Small output truth tables.** The final language function on m input bits has a trivial table with 2^m entries. A history-bit circuit also receives a time address of approximately q*m bits, so its generic table instead costs approximately 2^(q*m). Verifying a guessed final-output table against the original computation still needs a separate shortcut. No quantitative easy-witness or input-length self-reduction removing this address cost was found.

**Printing versus point queries.** The unresolved circuit condition concerns a word generated in time comparable with its length. It should not be conflated with an arbitrary E truth table. Printing all values of a function whose individual evaluations cost 2^(c*n) takes about 2^((c+1)*n) time. For a conjectural printing-to-circuit exponent gamma at least 1/2, gamma*(c+1) is at least min(c,1), so this substitution alone does not beat the usual direct-simulation/truth-table circuit bounds. This observation neither proves the conjecture nor supplies the required fast random-access decoder.

No unconditional universal power saving emerged from these tests. The checked actual-machine-to-local-game bridge remains available if one is found.

Let B be the sum over targets of (cardinality minus one). Suppose the only NOT gate reads original input v, and v occurs in d targets, where d is at most two.

Set v to false. The NOT becomes the constant true. Traverse the original gate list in order, maintaining for every old wire either a Boolean constant or a wire of the new circuit. An old index that did not yet exist is represented by false, exactly as the evaluator specifies. Fold constant inputs of AND/OR gates and omit the resulting constant or identity gates. Gates with no inputs or one input are folded as well. Constants remain symbolic and never require an added gate. Thus the new circuit is monotone, has binary AND/OR gates only, and preserves every nonconstant restricted output.

If d is positive, some target contains v and at least one other input. Its output is neither input v nor the NOT wire: the other target input distinguishes it from v, and the all-zero input distinguishes it from NOT(v). The output changes between the all-zero input and the singleton input v. Therefore an AND/OR gate other than the NOT must read either original input v or the NOT output wire. Otherwise induction through the gate list shows that every wire other than those two is independent of v. The identified gate also folds under v=false, so at least two gates disappear. This remains true if it mentions the NOT wire before that wire exists, because that earlier read is the constant false.

Each restricted target is S_i with v erased. It remains nonempty because the original size is at least two. Pairwise intersections still have size at most one. Its contribution to B drops by exactly one when v belonged to it and otherwise does not change. Consequently the restricted cost sum is B-d. Singleton targets contribute zero and can be omitted when applying the ordinary monotone lower bound. If L is the original gate count and Lprime the normalized count, then B-d <= Lprime <= L-2, so B <= L whenever d<=2.

If d is zero, every target is unchanged. Constant folding still removes the NOT, and the monotone bound gives B <= Lprime <= L-1. The case with no NOT is the ordinary monotone lower bound directly.

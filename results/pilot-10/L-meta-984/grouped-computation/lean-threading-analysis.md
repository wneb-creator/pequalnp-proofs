A decide +kernel auxiliary check is synchronous inside its theorem worker: Lean/Elab/Tactic/Decide.lean:129 temporarily sets Elab.async false while creating the auxiliary lemma. A single large finite span therefore does not itself use several workers. Independent chunk theorems can run concurrently. Emitting all definitions, then all independent concrete checks, then their dependent joins and semantic results should expose more work; the current low CPU utilization was not experimentally attributed to a specific declaration dependency, so this is a scheduling recommendation rather than a verified diagnosis.

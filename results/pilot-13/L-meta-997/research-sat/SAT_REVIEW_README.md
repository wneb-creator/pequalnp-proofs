# SAT and independent-review supplement

These files preserve bounded searches and independent Lean helper reviews. No actual counterexample to L-meta-997 was found.

## Actual Boolean synthesis

`sat_family_synthesis.py` builds AND/OR tail circuits after a fixed one-NOT prefix, calls the Lean-distributed CaDiCaL, checks every clause of any SAT model, then evaluates every input assignment before accepting a circuit. Any failed outputs supply additional CEGIS samples. Prefix `factors` fixes only three disjoint meeting OR outputs plus their conjunction and NOT; prefix `all` fixes all meeting OR outputs before the same H/NOT.

- n12, prefix all, 8-gate ordinary-OR control: SAT in0.30s, all4096 inputs verified, no inequality violation.
- n12/n14/n18, prefix all, tails2/4/8 respectively: UNSAT in0.013/0.052/94.9s on52/56/64 samples. This excludes ONLY those specified fixed prefixes and budgets, not the posted statement.
- n12/n14, prefix factors, tails20/28: 300s timeouts, UNKNOWN. n12 ordinary control with26-tail also timed out at60s. No timeout is interpreted as UNSAT.
- Initial n12 control suppressed the witness through a solver flag and its parser assertion failed; the separate v2 control corrected that option and passed all checks. The unsuccessful log is preserved.

## Set-only direct-sum probes

`sat_two_colors.py` uses exact finite bitset semantics, unrelated to full Boolean input semantics. Free sources are all partial transversals (at most one point per disjoint color) plus the full set. To reproduce an earlier source ordering/class exactly, pass `--sources-json` the associated result JSON; early three-color runs contained full transversals and singletons, while the later `partial` runs include all partial transversals.

- Two colors of size4,5 with5,7 paid gates: UNSAT in0.126/6.29s. Size4 control with6 gates: SAT and clause/set validation passed.
- Three colors of size3,4, all partial transversals, with5,8 paid gates: UNSAT in0.041/19.87s.
- These finite checks DO NOT imply an arbitrary-color direct-sum theorem. A known16-color,size16 abstract coding construction uses168 gates versus ordinary240.

## Preserved diagnostics

Every program log and every solver stdout+stderr log is complete. Result JSONs record exact sources/families, fixed prefixes, budgets and solver outcomes. CNFs and raw witnesses remain in scratch but are omitted from this small archive; they are deterministically generated by the scripts and recorded parameters/source JSONs. Source path/Lean assumptions for all independent helper checks appear in the full review logs. Only standard axioms propext, Classical.choice and Quot.sound occur. The official plain-file guard continues to reject the partial proof file with `the file holds no theorem`; no completed posted proof is claimed.

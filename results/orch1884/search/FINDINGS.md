Concrete search findings

1. Primary-wire bypass. Let C be an AND/OR circuit computing a graph edge function, and let G be an internal gate. If an earlier wire u has the same values as G on every minimal positive edge assignment, and u≤G on every maximal independent assignment, replacing every use of G by u preserves the graph function and deletes G. Positive outputs are unchanged; all negative outputs can only decrease. The edge/maximal-independent test set is complete by monotonicity. For the dual-rail search the same argument uses the complete positive/negative boundaries of each fixed-x0 cofactor. No minimum-leak assumption is needed.

2. Two four-gate H implementations are removable. For an independent triple {a,c,d} and an edge ab, H=a(b∨c)(b∨d)=ab∨acd. If the circuit first forms M=(b∨c)(b∨d)=b∨cd, M can be bypassed by b because cd is a nonedge. If instead it first forms G=a(b∨c), patch G to raw a∧b. This preserves all edge values and decreases every other value. The final H then becomes (a∧b)(b∨d)=a∧b and can be deleted. Both arguments allow arbitrary sharing of the intermediate wires. This describes these explicit implementations, not an exhaustive classification of every four-gate cone.

3. Five-gate productive H prefixes exist. Three raw OR clauses followed by two ANDs give nine distinct admissible boundary truth functions after all earlier-wire bypass checks. One example is H=(x0∨x7)(x0∨x8)(x1∨x5), combining the first and third clauses first. Its minimal positive edges are 01 and05, and it accepts the independent triple {1,7,8}. All512 inputs satisfy H∧OR{0,3,4}≤F0. The family census and explicit gates are in h5-cnf-family-result.json. This is not a census of all five-gate circuits.

4. The nine-variable cofactor has exactly three vertex covers of minimum size five. The standard16gate star-cover circuit is fully verified. No available wire covers two of the three A-singletons, so there is no shared partial neighbor-OR for the simple extension. An independent exhaustive truth-vector search found no extension by at most two additional AND/OR/NOT gates, even allowing free x0, its complement, and free constants. This only concerns the fixed baseline circuit.

5. The checked Petersen AND-count bound six implies a cofactor AND-count bound five via the free-OR model: extend the cofactor by one AND computing x0∧OR(A) and OR the output. Formal use still needs the routine translation/extension bridge; no new Lean theorem is claimed here.

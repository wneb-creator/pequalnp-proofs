# Independent finite-field checkpoint and ordering review

Verdict: PASS for bounded research use. This adapter preserves restart inputs, not an interrupted F4 execution state or a certified Gröbner basis. A finite-field unit result remains a finite-field diagnostic, not a characteristic-zero or Lean proof.

All 14 hashes in `checkpoint/provenance.json` match the frozen files. Exact source comparison found only the checkpoint include and three calls in the F4 core: after initialization, after a successful completed round, and after final reduction. The existing arithmetic and conversion implementations are unchanged. The wrapper diff only adds finite-field checkpoint configuration and its argument validation; native solver arguments retain their reviewed values.

Each snapshot keeps the complete original-generator prefix, then appends active basis rows selected through the same `lmps` indices as the upstream exporter. The coefficient-width selection and exponent extraction match the upstream export convention, including omission of the internal degree entries. Canonical residue conversion and zero-term filtering preserve each polynomial. The original prefix is copied before the solver can mutate its input. It is retained across restarts rather than recursively appending an earlier snapshot's entire generator list. The Python runner checks the current input's prefix against the specified base input coefficient by coefficient modulo the field, with identical exponents.

Original generators plus polynomial consequences generate the original ideal. Omitting redundant or inactive basis rows therefore does not change that ideal, although rebuilding pairs can repeat work. This argument relies on the reviewed native engine's ordinary consequence invariant; a checkpoint itself supplies no derivation certificate for those extra rows.

Snapshot publication flushes and fsyncs a temporary input before atomic rename, then does the same for latest metadata. Old snapshots are removed only after the new metadata is published; the ordinary completed path keeps the latest two. An interruption between publication steps can leave an extra file, but the previously published metadata still points to an intact snapshot. This is process-interruption robustness, not a claim of full filesystem power-loss durability. All failures/limits retain explicit non-verdict statuses.

I independently parsed all retained control snapshots, all completed bases, and their recorded hashes, using a fresh checker rather than importing the author's control script. Across unit, nonunit, and rational examples over primes 101, 1009 and 65537, 54 snapshots preserved the exact base prefix and all 126 appended rows reduced to zero against independently computed SymPy ideals. All 21 completed bases, including resumed runs, matched those ideals' reduced monic bases. The mismatched base-prefix test is rejected before engine startup. These controls exercise all three native coefficient widths; no new native or heavy solver run was needed for this review.

## Gate-charge strategy

The punctured double star of each incident flag `(p,l)` consists of the other `q` points of `l` and the other `q` lines through `p`. These are `N(q+1)` distinct maximal independent assignments and induce opposite forced answers on the two adjacent flag families in the monotone Karchmer–Wigderson game. The full flag-versus-flag game is nevertheless insufficient for a sharp all-order lower bound. `results/orch/search/gate_charge_double_star.md` gives an explicit monotone separator on coordinate planes `PG(2,q)` for odd prime `q`, accepting every true input and rejecting every punctured double star in `O(q² log⁴ q)` binary gates. The partition uses `q` translated parabolas and `q+1` singleton points at infinity on each side. Every negative test meets each block at most twice. Shared bit buckets and dual-rail arithmetic test each block pair in polylogarithmic size. An explicit order-seven independent assignment is accepted by the separator. This is a mathematical diagnostic, not a Lean theorem or counterexample to the desk statement. No submission is warranted from this result.

A general switch count strengthens the private-center tight-AND argument. If an exact monotone circuit has `a` binary AND gates, let `d(Z)` count the ANDs whose operands differ on maximal negative `Z`. Fix the false operand at each such gate and choose either operand at every equal one. Each of the resulting `2^(a-d(Z))` switched circuits preserves all gate values on `Z` and computes a linear OR that dominates the original function. Its largest false input must be `Z` by maximality. Hence `sum_Z 2^(a-d(Z)) <= 2^a`. In particular, if there are `2^a` maximal negatives, every AND has unequal operands on each and is false there. Monotonicity puts every AND below the target everywhere. For `k` centers with a private point at each, there are `2^k` maximal negatives; a circuit beating the C4-free star bound needs at least `k+1` ANDs, since the sharp bound for clean ANDs applies at equality. When `a=k+c`, the uniform average of `2^(number of equal-operand ANDs on Z)` is at most `2^c`. These are mathematical arguments. No Lean build or checker verdict is claimed for them.

Distinct maximal negatives must have an AND gate whose two operands swap values between them, since their allowed selector subcubes are disjoint. In the cyclic order-three plane direct enumeration over `8192` point subsets finds all 52 flags have 18 pairs of maximal negatives that exchange just the two endpoints. The analogous Fano enumeration finds no such exchange. For every odd prime coordinate plane, normalize the flag to vertical infinity and the infinity line. Take all affine parabola points `(x,x²)` and all affine nonvertical lines missing the parabola. Each vertical meets the point set; each finite slope has a missing line since `x²-mx` has only `(q+1)/2` values. Each off-parabola point `(a,b)` lies on a missing line: the discriminant of a line of slope `m` through it is `(m-2a)²+4(b-a²)`, which is a nonsquare for some `m`. Indeed for nonzero `c` there are exactly `q-1` pairs solving `u²-t²=c` by factoring, so the quadratic-character sum of `t²+c` is `-1`. Thus this independent context dominates all other vertices and either flag endpoint completes it to a maximal independent set. There is no per-gate upper bound on the number of exchanges served in this argument. No unrestricted sharp gate count follows.

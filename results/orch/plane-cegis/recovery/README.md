# Posthoc native-result recovery

The environment transition left the first final native solver running while its Python wrapper became a zombie with kernel wait status9 (SIGKILL). The cause of that kill is not established. Its original automatic validation did not complete. The standalone checker reads the persisted, pinned CNF/mapping and any actual model, checks every clause in both polarity conventions, decodes strict backward binary gates, regenerates all756 boundary rows, and checks clean/dirty and joint-read flags. It distinguishes kernel wait status, native log exit code, and unavailable original wrapper history.

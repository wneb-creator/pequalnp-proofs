1. Pruning order and memo semantics

The new DFS checks exact signed row separation and cofactor bounds before
canonicalization. These cuts concern only the current truth-function pool
and remaining budget; their position does not alter the searched domain.
A cofactor history is a constructive supply witness, not a transition
restriction. All 120 Petersen symmetry remains valid. Integer signal IDs
have a fixed injective registry within the run, and the input-prefix
optimization retains precisely the transformations that can minimize the
full sorted state. Cached equal canonical states therefore have equal
budgets and isomorphic current pools.

Memo insertion occurs before expansion, but every recursive edge strictly
decreases budget. Thus an equal-budget memo reference cannot point to an
active ancestor. Exceptions abort the run and mark unwound ancestors open;
they cannot subsequently masquerade as completed exclusions. The independent
smoke audit additionally checked prior completion and an explicit graph
automorphism for every memo reference.

2. Branch completeness

For each unordered pair of distinct current signals, the DFS generates all
four signed operations. The two asymmetric operations cover both operand
orders. It generates all four retain/delete combinations. Skipping zero or
an output already in the pool agrees with necessary Live properness and
freshness; possible extra nonproper branches only enlarge the search.
The cardinality prune follows child.card <= childBudget+1. The one/two-cover
bookkeeping removes exactly the columns lost by deleting operands and then
adds the new output column. Its sampled signed row pairs supply a necessary
condition; all-positive exact row separation provides a stronger later cut.
No first-gate-history or lexicographic gate-order restriction remains.

The trace records actual visited children. It does not record every skipped
candidate, so complete branch coverage must be regenerated by a certificate
checker. I independently regenerated all 513 child cases at the smoke trace's
one completed expand node; its recorded children match exactly.

3. Exact witnesses and lower-bound scope

Each recorded incoming gate is a truth-table-exact normalized signed binary
operation. Each row witness is a target-positive/target-negative pair on
which every current function agrees. Each cofactor mask can be reconstructed
from the fixed 1,145-profile table. Its recorded bitmask indexes the filtered
projected-history definitions, not the original history; I independently
rebuilt these definitions and checked exact selected masks, constant-root
mass, supply closure, and the strict lower-bound inequality.

A future found result must be independently replayed from primary inputs,
including terminal formula gates printed in the final history. Verify every

# Global plane circuit search

This is heuristic counterexample search for the exact 42-input incidence function in L-meta-1477. It does not establish a lower bound. No valid circuit of size at most 124 had been found when this snapshot was frozen.

`SearchPlaneProblem.json` contains the posted 105 ordered edges and all 25,237 maximal independent input assignments. The data was generated by neighborhood-union closure and independently regenerated from all 2^21 subsets of the left part. Every stored negative assignment was checked to be independent and maximal. These are computational checks, not Lean proofs. All six listed Singer multiplier automorphisms were checked against every edge.

The search evaluates each candidate on 105 minimal positive assignments and the 25,237 maximal negatives using integer bit masks. A candidate that passes is expanded into a concrete binary AND/OR gate list and independently evaluated on all 25,342 assignments before it is saved. Monotonicity makes this extremal test set sufficient for Boolean equivalence. Any claimed result still requires the repository Lean checker.

Sources use point or line star bases, randomize the ordering and Singer coordinates, and introduce shared linear OR forms and latent AND helpers. Unreachable nodes do not contribute to the reported gate count. Negative error weights are varied across restarts because one incorrect nonedge can affect many thousands of maximal negatives. These weights guide search only; a saved valid circuit always has zero errors on the full test set.

Run001 used one or two latent AND helpers and was stopped to broaden diversity. Its complete log is `run001.log`; best valid size was 125. Run002 cycles one, two, four, and eight latent AND helpers. The source and data hashes are in `manifest.json`.

```sh
python3 results/orch/global-search/SearchStochasticPlane-v2.py --seed 14772904 --seconds 1200 --output-dir /tmp/oec/pequalnp-pilot-29/stochastic-plane-002
```

Twelve randomized baseline starts were expanded and checked on the full test set before these runs: they produced 125-gate star circuits or valid 127/129/133/141-gate circuits with activated helpers. The data and the v1 evaluator/decoder have independent agent review; v2 changes only the latent-helper schedule and its descriptive header.

The running source remains under `results/orch/lemmas/`; this directory is a frozen reproduction package. Logs for live runs remain under the task scratch directory and should be copied after completion.

# Reproducing the64-gate positive control

The complete checked source is ../lemmas/Meta3773Control64Split.lean, SHA256 b99b6f82972f49b14c2167a0400653fb1b9be2e4c82e46bbdf61a40e7f2a0f98. Its full Lean check passed in283.2746seconds with peakRSS4,781,682,688bytes. It constructs64 binary monotone gates, begins with OR(input0,input1), accepts all52 incidence pairs and rejects all756 listed negative tests. This is a positive control only: L-meta-3773 asks for at most63 gates and remains unproved here.

The bottleneck was constructing26 packed808-bit input words directly from the Lean finite sample definitions. Each column is now proved separately by kernel reduction, then assembled by pointwise/list extensionality. On the resulting literal words, replaying the64 gates takes1.425seconds. Every computational equality uses decide +kernel, with no native_decide or new axiom.

To regenerate in a disposable copy of this directory, run meta3773_input_words_generate.py, then geometry-meta3773-control-split-generate.py --output NEW.lean. The first generator writes the input-word JSON and Lean component sources in its own directory. The second reads the fixed64-gate template and reviewed components and produces byte-exactly the checked source. The template is intentionally named .template.txt: its original standalone whole-computation tactic did not pass the resource cap and is not the final proof. InputWords is an extracted component whose validation is the successful complete file; it was not separately rerun after the final API correction.

For provenance, the earlier full split attempt is preserved as geometry-control64split-v1.failed.txt with its full log/status. All26 column kernel checks finished, but the file failed because List.getD_eq_getElem was called with the wrong explicit arguments in the list-extensionality lemma. The final source replaces that one rewrite with the already tested getD/getElem? chain. Older monolithic resource failures and the initial narrow-import Nat-notation failure are also preserved as logs/status. None is a successful control proof.

Both encodings here use true/1 for OR and false/0 for AND. This differs from the separate reduced-core CGP encoding. The808 rows include52 positive samples and756 negative sample entries; duplicates are retained in their exact original ordering, including reverse lexicographic sublistsLen order within each cardinality. Do not substitute the separate756-row full-search dataset or the737-row reduced-core dataset.

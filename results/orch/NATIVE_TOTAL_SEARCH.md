# Native total-gate model

`lemmas/CounterexampleTotalSat.py` represents a fixed number of binary AND/OR gates, reading primary inputs, earlier gates, or a free false source. It currently does not represent a true source or empty AND gates; any use for general lower bounds needs the corresponding constant-elimination argument. SAT witnesses are checked on the full Boolean cube and converted to explicit gate lists.

Each operand has exactly one source selector. Commutativity permits ordering the two selected source indices. The last gate is the output, and every earlier gate must be selected by some later gate. This excludes unused gates; at-most-size instances can be padded by repeated-input OR gates after discarding unused gates. Source/output truth variables use every graph edge as a positive sample and every maximal independent set as a negative sample. Monotonicity makes these samples sufficient for exact graph-function semantics.

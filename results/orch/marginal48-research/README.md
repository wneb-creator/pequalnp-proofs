# Fixed 48-OR marginal circuit: research and invalid repair seed

Recorded 2026-11-25 for L-meta-1896. This directory does not contain a proof or a refutation of the posted statement.

The explicit circuit has 26 inputs, 48 binary OR gates and 24 binary AND gates. Python replay checks all 2952 inputs of weight at most three and all 468 prescribed generic negative rows. Its weight-zero, singleton and pair behavior is exactly the 52-edge projective-plane incidence function. It has 108 mixed nonedge triple errors and accepts 378 prescribed negative rows. Thus it is a small counterexample to the unrestricted quadratic-shadow auxiliary claim, but it fails the actual gap's hypotheses.

`pg3-marginal48.py` constructs the affine-to-Singer label mapping, the full 98-wire circuit, its canonical AND-list representation, and the finite reports. Its only input file is the preserved `theta4-control-global51-masks.json`; that filename identifies the previously checked sample order and does not make the 48-OR circuit a valid control. `canonicalize-marginal48.py` then replaces each AND operand by all earlier canonical signals whose positive support contains its support. Every positive flag is preserved and no negative wire value increases. The final number of forbidden rows remains 378.

Run both scripts from this directory with Python 3. Full original and portable replay logs are retained. The portable copies differ from the initially audited scratch scripts only by resolving their data directory relative to the script location.

`pg3-marginal48-canonical-invalid.json` and its matching masks are deliberately invalid inputs for repair search. They include the zero-based OR-group map. `MarginalSeed48.lean` is generated data only and has not been compiled. No file in this directory asserts a checked counterexample.

`MarginalShadowControl.lean` is a source-only certificate prepared for a later build window. Its 678-bit sample table covers all 676 ordered pairs of input coordinates, one empty input and one failing generic row. Diagonal pairs are singletons, so the first 677 positions cover all 352 distinct assignments of weight at most two. Its intended conclusion includes that the circuit accepts a specific admissible generic negative, making its limited scope explicit. `prepare-shadow-certificate.py` reproduces the source and mask data from the invalid seed, and independently checks the 678 Boolean answers in Python. The source has not been compiled. `marginal48-quadratic-shadow.json` is counterexample agent's independent replay diagnostic.

The fixed-base obstruction is separate. For the generic negative with points {0,1,5} and lines {3,6,7,8}, every cover of all 52 positive flags by old wires that are false at this negative needs at least nine wires. The independently audited proof and 12 maximal-support masks are in `../pg3-marginal48-cover-review.md` and its associated audit files. An extension retaining the old wire functions and using K additional binary ORs can expose at most K+1 such old wires on a false frontier. Hence it needs at least eight appended ORs, or at least 56 total when all 48 original ORs are retained. Rewiring or deleting original gates is outside this conclusion.

The source-only general lemma is `../lemmas/CanonicalExtensionCover.lean`. It works directly with the previously checked canonical Program representation and arbitrary old-wire valuations. It has not been compiled, and no general arbitrary-circuit-to-Program conversion is claimed by that source. A separate source-only finite support certificate is being prepared. All Lean builds were intentionally paused during the primary SAT search.

The broader obstruction to degree-three-only arguments is documented in `../quadratic-shadow.md`: three diagonal shears of an affine marginal circuit are correct through weight three but have a mixed quartet error. At q=17 they use 4851 OR gates for 4913 incidence edges. This rules out a uniform strengthened C4-free auxiliary theorem; it does not establish anything about the 51-OR target at q=3.

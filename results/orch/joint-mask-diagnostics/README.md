# Finite two-product mask diagnostics

These are computational diagnostics about candidate normalization lemmas. They are not a counterexample to the posted plane gap and do not prove a general lower bound.

`SearchJointUnion.py` evaluates every assignment of each explicit six- or eight-vertex host. Each product is a conjunction of two nonempty OR clauses and is required to be dirty. A clean joint means the conjunction of both products never accepts a host-independent assignment. Productive means a host edge is accepted jointly. An effective variable mask means conjoining that variable to the product is globally below the host function. The union U contains all host-edge pairs accepted by any such mask, and all jointly accepted host-edge pairs.

The ordinary counterexamples refute cover-at-most-two claims, including a private joint and disjoint operand versions. The overlapping-operands edge-budget counterexample has seven union edges and four OR gates, so U exceeds K+2. Its four clauses are incomparable but each pair overlaps; it does not address the disjoint conjecture.

For disjoint operands A/B and C/D, each clause of size at least two, `--edge-budget` uses the explicit shared-quadrant construction K=sum(|clause|-1)-sum(max(|cross intersection|-1,0)). Equivalently K+2=N+r-2, where N is the number of distinct clause variables and r is the number of nonempty cross intersections. The five eight-vertex hosts have 2,037 distinct product functions, and all 2,073,666 pairs per host were tested. No U>K+2 was found. The separate `SearchJointTight.py --tight-example` also searches equality and found none on five six-vertex and five eight-vertex hosts. This is bounded evidence only; the host lists are not all bipartite C4-free graphs. A tight-example JSON retains the historical `counterexample` key, but marks `is_counterexample` explicitly when it contains an equality witness; these runs found none.

Reproduction: `python3 SearchJointUnion.py --output result.json --vertices 8 --disjoint-min-two --edge-budget --seconds 60`; replace the script with `SearchJointTight.py` and add `--tight-example` for the equality search. The default script searches a cover-two violation; add `--private-joint` and optionally `--disjoint-min-two` to reproduce the private examples. All logs are complete. The overlap example is an independently replayed explicit fixture, not a census result.

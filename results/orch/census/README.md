# C4-free graph census, 2026-11-24

This census contains one graph from each isomorphism class generated by nauty geng. It does not establish any circuit lower bound. The connected minimum-degree-two subfamily is a search heuristic, not an exclusion theorem for other graphs.

Source: https://github.com/cando-developers/nauty at commit 4fedb86cbf2f7547ee8ad91245af56d7d3c554bf (nauty 2.7r1). The source archive was fetched from GitHub, inspected, configured, and built in scratch. Complete build and fetch diagnostics remain under /tmp/oec/pequalnp-pilot-31/census/. No third-party source or binary is included here.

Commands, from the built nauty source directory:

```sh
./geng -f -l -v 8 >c4-all-8.g6 2>c4-all-8.stderr
./geng -f -l -v 9 >c4-all-9.g6 2>c4-all-9.stderr
./geng -f -c -d2 -l -v 8 >c4-core-8.g6 2>c4-core-8.stderr
./geng -f -c -d2 -l -v 9 >c4-core-9.g6 2>c4-core-9.stderr
```

The runtime help is preserved. Here -f forbids four-cycles, -c requires connectedness, -d2 requires minimum degree two, and -l canonically labels the graph6 outputs.

Counts: all graphs on eight vertices, 351; all on nine, 1230. Connected minimum degree two: 28 and 112. A seven-vertex control census contains 117 graphs, exactly five with nine edges, matching the separately obtained extremal-class census. The maximum edge counts on eight and nine vertices are 11 and 13.

The analyzer independently decodes graph6, checks the absence of four-cycles both via common-neighbor counts and explicit four-vertex cycles, enumerates every vertex subset to compute independent sets and covers, verifies tau = n - alpha, and checks maximal independent sets. Vertex degree, neighbor-degree and triangle invariants distinguish every generated class; no pair required the exact backtracking isomorphism fallback. The filtered full census agrees exactly with geng's separate connected/minimum-degree-two run.

Each JSON row contains edges, exact edge_count and tau, a minimum_cover, maximal_independent_sets as bitmasks, bound = |E| + tau - 1, and target_size = bound - 1, plus structural statistics. Rows are sorted by decreasing edge count, tau and triangle count. The full JSONs and combined core JSON can be regenerated by running `python3 analyze.py`; by default it uses its own directory. All graph6 data needed for this regeneration are included.

The analyses are executable finite checks, not Lean certificates. Generator completeness relies on the pinned nauty program. No exact circuit synthesis result is asserted by this census.

# Exploratory computational records

Python scripts, JSON data, and logs in this directory are exploratory CAS and numerical records. They are not Lean-checked proofs of L-gct-231 and do not establish any conclusion over the complex numbers unless a corresponding Lean lemma explicitly states it.

Finite-field exhaustive searches cover only their named fields. Numerical searches can miss solutions. Restricted-family Groebner calculations require separate parametrization and coverage proofs before they can imply a statement about arbitrary spaces. Historical absolute scratch paths remain in the scripts.

The .lean files are separately compiled partial results. Their precise scope, build outputs, and review status are recorded in ../validation.txt. The posted dimension-3 existence statement remains unresolved.

The checked generic normalizer emits at most one strict-Dag gate for each original gate with at least two inputs, and none for a constant or unary gate. The resulting ordinary function is unchanged. Consequently, a monotone fan-in-two circuit with any constant or unary gate either computes a constant or input projection, or has an equivalent strict Dag with strictly fewer gates.

This is a size-count component for surgery arguments. It does not assert that replacing any particular internal gate preserves the function, the boundary rows, or the derivative traces. Those premises must be proved separately before using the saving to contradict a minimal-size bound.

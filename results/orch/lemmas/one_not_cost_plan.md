# Unverified cost-erasure plan, stopped at lease expiration

At 2026-11-25 14:39 UTC the parent reported HTTP 410 and instructed all proof development to stop. No Lean implementation of this plan was written or checked. Existing `one_not_*.lean` helpers remain the checked artifacts; this note is only a continuation guide.

The intended bridge takes a circuit `pre ++ NOT ins :: post`, with AND/OR-only prefix and suffix, and a Boolean constant `b` such that replacing the NOT output by `b` preserves a nonconstant target function. If some suffix gate reads the replaced wire, constant propagation should erase the NOT and at least one suffix gate. This gives a monotone circuit of size at most original size minus two. If the NOT is unused, only one gate is saved, which is insufficient to turn a size-19 circuit into a size-17 monotone circuit.

Relevant existing implementation: `lean/PEqualNP/MetaComplexity/Helpers/Elim.lean`, approximately lines 1–313. Its `elim_len_lt` lemma already proves that if an initial status is constant and some suffix gate reads it, then the final emitted-gate count is at most the old count plus suffix length minus one. The constant status persists across the suffix, so this proof handles shared uses. Its `inv_elim` proves semantic preservation and validity of status aliases. `elim_ok` proves emitted gates satisfy the allowed basis and fan-in bound.

That helper cannot simply be imported into the final proof because only the posted imports and Mathlib imports are allowed. A self-contained adaptation can represent statuses by `Bool ⊕ Nat`, avoiding the helper's custom inductive type. Required supporting facts are `wiresFrom`, its length/append/prefix properties, and elementary `getD` facts. The final adaptation would need a separate induction showing that simplifying an AND/OR-only suffix emits AND/OR-only gates.

For `m = n + pre.length`, initialize statuses as `List.ofFn (fun i : Fin m => Sum.inr i.val) ++ [Sum.inl b]` and initialize emitted gates as `pre`. These statuses describe the old wire vector `wiresFrom pre inputs ++ [b]`. Run the adapted elimination over `post`. The semantic invariant relates every old wire to a constant or valid alias in the emitted circuit. The output status cannot be constant because the target function is nonconstant; its alias becomes the new output index. The strict length lemma applies under the explicit syntactic hypothesis `∃ g ∈ post, m ∈ g.inputs`.

No monotone lower bound, comparability criterion, output-cone claim, or final Petersen theorem is proved by this plan. The previously checked functional comparable-input lemmas may supply the replacement-preserves-function premise later. The new bridge should retain that premise explicitly until such an application is formalized.

# Normalization for the unrestricted SAT search

The intended SAT search class allows 10 primary Boolean inputs, a free false wire, binary AND/OR with repeated operands allowed, unary NOT, all operands referring only to existing wires, and the final gate as output. At least one NOT must occur. The following normalization is cost preserving or decreasing; it does not justify versions forbidding repeated operands or false, or requiring every gate to be live.

1. A circuit computing Petersen cannot output a primary input: on each singleton input Petersen is false, whereas that primary input is true on its singleton. It cannot output a missing wire, since Petersen is true on the input with vertices 0 and 1 true.
2. Therefore the output names a gate. Remove all gates after that gate. Evaluation of the output is unchanged. The shortened circuit's output is its final gate.
3. Give the circuit one additional free false wire after its primary inputs, shifting every old gate-wire index by one. At gate position j, replace a read of an old wire index at least n+j by the free false wire. This agrees exactly with the root semantics of invalid and forward reads.
4. Normalize each operation without changing its gate count: AND with no operands becomes NOT(false); OR with no operands becomes OR(false,false); unary AND/OR becomes the same binary operation with a repeated operand; NOT retains only its first operand, using false if absent; binary AND/OR keeps its two operands.
5. If the trimmed prefix still contains an original NOT, normalization retains it. If it contains no NOT, at least one original NOT was removed in step2, leaving one gate of spare budget. Insert NOT(false) before the normalized prefix and shift all its gate references one further slot. This NOT is unused, retains the desired function and restores the positive-NOT condition. The output remains the last gate, and total cost does not exceed the original cost.
6. If exactly19 gates are required, append OR(output,output) identity gates until that length. The last appended gate is the output; existing NOT remains present.

`NormalizeForSat.lean`, `TruncateForSat.lean`, `DeadNotPad.lean`, and `IdentityPad.lean` now compile. `SatNormalizeComplete.lean` combines the first three into canonical last-output normalization with no cost increase. `SatNormalizeExact.lean` also compiles and combines exact-budget identity padding. The named partial file `lean/PEqualNP/Outside/L_meta_2592.lean` specializes the result to Petersen and budget19; its first `lake build PEqualNP.Outside.L_meta_2592` passed (exit0, 2026-11-25 around14:09UTC). All generic proofs have been independently reviewed. This establishes the intended class normalization, not the SAT formula encoding or an UNSAT certificate. Sorting operands for an a≤b symmetry restriction is being formalized separately.

Important: an UNSAT claim for a more restrictive encoding (distinct AND/OR operands, no false wire, all gates live) is not justified by these notes. A SAT witness can always be checked directly regardless of completeness of the search class.

# Conditional gate alias surgery

The cached Lean package proves a generic replacement and normalization result. `GateOverride` fixes all original input values, out-of-range wire values, and every gate equation except one edited gate. A changed output therefore has a path of changed wires from that edited output. Agreement at the edited wire, or at the end of an explicit single-reader chain, propagates to the relevant later wires.

The concrete `overrideAlias` replaces the chosen gate by OR(B,B), retaining all indices. This intermediate Dag deliberately permits repeated operands and is not asserted Strict. Its evaluation satisfies the generic override equations and the unary-B equation. Replacing an AND this way can only increase wire values. If the original left operand is true, all wire values agree. Alternatively, an explicitly unreachable false operand of a later AND barrier forces agreement at that barrier and after its single-reader chain.

The official Circuit corresponding to this alias contains a duplicate-input gate. The accepted ordinary normalizer emits zero gates for that row. The new count argument therefore produces a strictly smaller equivalent Strict Dag, or an explicitly retained constant/projection alternative. This normalization makes no derivative-preservation claim.

The final theorem `override_smaller_of_barriers` retains an explicit safety premise for EVERY original false-output assignment: either the edited left operand is true, or there is a suitable false, unreachable AND-barrier operand on the edited output's single-reader chain before the output. Under that premise it proves ordinary equivalence to the original function and a strict gate saving. This safety premise has not been proved for the outstanding Fano equality cases. Maximal-negative-only safety would additionally need a monotonicity/boundary-cover bridge; singleton support alone is not functional literal purity.

# Pilot 64 computational exploration

These artifacts are research partials. They do not prove or refute the posted L-meta-2602 statement.

- `plane-exact65.json` is a 65-gate circuit computing the full order-3 incidence function with both target directional derivatives false. The posted statement permits only 63–64 gates, so this is **not a refutation**. An independent scalar evaluator checked all 52 minimal true assignments and 704 maximal independent sets. The accompanying Lean formalization is in `../lemmas/Witness65.lean`; its validation status is recorded by the orchestrator.
- `plane-nearmiss64.json` has 64 gates and both derivatives false, but misses edge (point 8, line 8), input wires (8,21). It is **not a result** for the posted statement.
- `counterexample_search.py` exhaustively synthesizes small monotone circuits by truth-table and derivative signatures, and enumerates minimum vertex covers of the small planes. `counterexample-search.log` is its complete finished output. It supports only the explicitly listed small cases and ordinary star-partition facts.
- `plane_local_search_seed64.py`, `plane_local_search_seed65.py`, and `plane_local_search.py` reproduce full-plane stochastic searches with seeds 64, 65, and 66 respectively. The first objective permits losing the distinguished edge; later variants penalize that failure and use the 65-gate construction as a starting point. These searches are not exhaustive.
- `or_sums_boundary_search.py` searches for 38-gate, 13-output monotone circuits computing the thirteen four-variable disjunctions. It checks a sufficient 26-row monotone boundary basis and would verify any success on all 8192 truth assignments.
- `cycle6_or4_search.py` searches for a 6-cycle edge-function circuit using four OR gates and arbitrarily many AND gates, flattening each AND-only region into a conjunction mask. This search is not exhaustive.

The three full-plane runs, boundary OR-sums run, and C6 run each lasted 20 minutes. The full-plane runs tried 13,833,414, 11,596,493, and 11,039,571 candidates respectively (36,469,478 total), with no counterexample. The corrected seed-66 run still has one missing non-target edge. The boundary OR-sums run tried 9,806,727 candidates; its best circuit computes twelve outputs exactly and misses one required singleton for the thirteenth. The C6 search found no exact circuit; its best circuit wrongly accepts precisely the nonedges {1,4} and {2,5}. The separate full-table OR-sums run with seed 6401 lasted 30 minutes and tried 2,854,672 candidates; its best result still differs from the target in 512 truth-table bits. Complete logs and best candidates are preserved beside the scripts. None of these heuristic failures is an impossibility certificate.

The bounded repair SAT experiments are documented in `metadata.json`, which records source versions, arguments, hashes, complete retained outputs, and omitted reproducible CNFs. `path_center_audit/` independently audits the four-input control, and `double_star_audit/` records computational coverage of the eight-input nine-gate double-star search. `kernel_lrat_control/` preserves a kernel-checked UNSAT proof for the explicit four-input control CNF; its circuit-to-CNF interpretation is not formalized. These results do not establish the posted projective-plane lower bound.

Run the stochastic scripts with Python 3. The `plane_local_search*`, `or_sums_boundary_search.py`, and `cycle6_or4_search.py` scripts accept `--seconds`, `--seed`, and `--out`. The separate full-table search uses `or_sums_search.py <seed> <seconds>` and writes its outputs under the job scratch directory. These stochastic scripts need no external solver or nonstandard package; the separate SAT experiments use the solver recorded in `metadata.json`.

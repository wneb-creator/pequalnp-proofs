# Historical search artifacts

This folder preserves older source/data files and complete historical logs from the counterexample agent for pequalnp-pilot-94. Relative scratch paths are retained to avoid filename collisions. These are historical artifacts, not additional validated results. Some are superseded implementations, extra controls, interrupted runs, or repeated data already summarized elsewhere. No new search was run to create this archive. Regenerable CNFs and binaries are intentionally excluded. See HISTORY_MANIFEST.json for exact source paths, sizes, and hashes.

# A quadratic defect for numerous mixed features on two lines

This mathematical example limits the full-boundary component-column rank method. It supplies no smaller circuit.

Choose two lines B,D in a projective plane of order s and retain all point labels on the two lines except their intersection. Call the retained labels p_1,...,p_s on B and q_1,...,q_s on D. Every other nonempty line is the transverse line y_ij through p_i,q_j. It contains precisely these two retained labels. Thus the point module has 2s centers, s²+2 line variables, 2s²+2s flags and a point-star circuit of size 2s²+4s−1.

Expose the mixed OR features p_i OR D for i in I and q_j OR B for j in J. For any real matrix z supported on I times J with every row and column sum zero, place +z_ij on flag (p_i,y_ij), −z_ij on (q_j,y_ij), and zero on every hub flag. The resulting vector is orthogonal to every permissible component column at every maximal negative.

Indeed, if y_ij is omitted then its raw input ties the two flags, so their opposite entries cancel. If y_ij is selected, both its endpoints are omitted. When D is omitted, the false feature p_i OR D ties the entire p_i-star to the D-star, and the omitted q_j ties its entire star to that same D-star through their common hub flag. Thus the two transverse flags belong to one component. When B is omitted, apply q_j OR B symmetrically. If both hubs are selected, no point can be selected; maximality then puts every line in the assignment. Its components are individual point stars, on each of which the matrix sums vanish. Nonmaximal negatives supply no additional rank, since moving downward to them only merges more components.

These independent vectors have dimension (|I|−1)(|J|−1) for nonempty I,J. Consequently the most general component-column span with the given features has rank at most the flag count minus this quadratic term. No choice of extra maximal-negative tests can restore the lost dimensions. In contrast, the comparison with the pure degree-two core controls the largest such feature sets. Setting both B,D to zero deletes all |I|+|J| displayed proxy gates. There must be at least one more deleted gate reading a hub outside this list: with every point true and every line false, toggling B or D flips the output while all the displayed proxies stay true. Removing these readers preserves the pure subdivision of the complete bipartite graph, whose sharp unrestricted size is 2s²+2s−1 by the separate degree-two carrier argument. Hence when at least 2s−1 displayed proxies are physically present, the original circuit already has size at least 2s²+4s−1. This deletion count is compatible with the rank limitation and leaves smaller proxy families unresolved.

# Projective-plane row modules

The catalog restricts the plane to a subset of points and all lines, then merges the line variables with the same singleton neighborhood into one input. The recorded multiplicities expand these variables back into OR trees. Any saving against the compressed point-star circuit yields the same saving in the full plane by adjoining untouched point stars. Each orbit consists of point sets carried to one another by projective coordinate changes. The catalog includes every 2–6 point subset in the Fano plane and every 3–6 point subset of PG(2,3).

The Python and C++ frontier solvers use the incident pairs and maximal independent assignments as boundary tests. They retain intermediate wires until their last use. A retained operand spends one unit from the excess of the gate limit over the number of inputs minus one. Each live state must distinguish every positive and negative test through some wire with values 1 and 0. Equivalent boundary signals and signals covering no such pair are excluded. The C++ version additionally identifies equivalent first steps under automorphisms of the compressed module.

The C++ private-cell test permits consumption of an operand precisely when every positive/negative pair uniquely covered by it remains covered by the new gate. A pair jointly covered by the two operands remains covered by their union or intersection. Positive controls are decoded into numbered gates and checked against every Boolean input by a separate program.

The logged UNSAT results are computational diagnostics for the listed modules and bounds. UNKNOWN records timeout. These runs do not establish a Lean lower bound for the plane circuit.

Regenerate the catalog and C++ instance files in an empty work directory with the Python source files on its search path. Run `fresh_modules.py`, then `fresh_frontier_instance.py`, compile `fresh_frontier.cpp` with `g++ -std=c++20 -O3`, and invoke the executable with the module instance filename, gate adjustment (minus one or zero), and time limit in seconds. The older Python solver accepts the special subdivided-complete-graph family. Its logged bounds exceed the number of inputs minus one. The SAT generator is a separate diagnostic based on the project's earlier finite-boundary encoding.

The instance generator also writes files ending in `pure.txt`. These retain only lines incident to at least two selected points. For at least two selected points every row remains active. Fixing a private leaf to zero removes at least one gate from any circuit that computes the module, since the input is essential until it is fixed and every first gate reading it simplifies. Removing all private leaves therefore lowers the unrestricted circuit cost by at least the number removed, exactly the change in the point-star benchmark. A lower bound on the pure core rules out savings for the corresponding full module. A candidate that improves the pure core needs a separate extension check.

The optional `fresh_frontier_cycle.cpp` adds a test based on the number of undirected cycles in a connected suffix. For each positive test e, take the set of coordinates that uniquely separate e from some negative. For each negative T, take the coordinates that uniquely separate some positive from T. Call these sets I and J for this test pair. Every positive proof subgraph at e contains the inputs in I, and every negative proof subgraph at T contains the inputs in J. Follow one true child at every OR of the positive proof and one false child at every AND of the negative proof. In the intersection, every common gate has a single common outgoing arc toward an input. Its connected components therefore end at distinct common input leaves. For two connected subgraphs of a connected graph, one fewer than the number of intersection components is at most the graph's cycle rank. This follows by counting vertices and edges in the union and subtracting the cycle ranks of the two subgraphs. Consequently a connected suffix needs cycle rank at least |I intersect J| minus one.

The cycle test applies to a connected suffix that uses all current live wires. A traced globally least circuit has exactly such a suffix when each operand is discarded on its actual last read. In that case the remaining gate budget minus the live-wire count plus one bounds its cycle rank. An arbitrary completion that ignores live wires can have a larger cycle rank. Exhaustion with this test rules out least-witness traces from the initial state and is not a general impossibility claim for arbitrary unused-input completions from every intermediate state. The positive control for the cycle version has the same decoded 11-gate function as the base control.

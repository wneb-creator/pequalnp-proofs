# A sharp OR-gate bound for formulas

This mathematical argument has not been formalized in Lean. Let $E$ be the set of incident flags of a finite projective plane. A monotone binary formula for the incidence edge function has at least $|E|-1$ OR gates. This equals the number used by a canonical point-star formula. The proof uses a communication tree and does not apply directly to a circuit with shared gates.

Use the positive input selecting exactly $p,l$ for each flag $(p,l)$. For each point $r$, let $M_r$ select $r$ and all lines nonincident to $r$. This is a negative input. Give $M_r$ one column for each line $t$ incident to $r$. Give the negative input selecting all lines and no points one column for each point $s$. Repeated negative inputs are allowed to carry different numerical columns.

Write $A_s$ for the indicator vector of flags at $s$ and $u_{r,t}$ for the coordinate vector of the single flag $(r,t)$. Assign column $A_s$ to the all-lines input tagged by $s$. To $M_r$ tagged by $t$, assign $u_{r,t}$ plus the sum of $A_s$ over all points $s$ on $t$ other than $r$. These columns span the full vector space on $E$, since every coordinate vector can be recovered by subtracting available point-star vectors.

Run the monotone Karchmer–Wigderson protocol for the formula. At an OR choose a true child using the positive input. At an AND choose a false child using the negative input. Deterministic tie choices suffice. The resulting tree divides the row-column matrix into rectangles indexed by gate occurrences and terminates at input variables that differ between the positive and negative assignments.

In a leaf rectangle labeled by point $s$, all rows are flags with point $s$. A column from $M_r$ can occur only when $r$ differs from $s$. Its entries on those rows all equal the indicator of $s$ lying on the tagged line $t$. The columns from the all-lines assignment are also constant on those rows. In a leaf labeled by line $l$, all rows have the form $(p,l)$. Only columns from $M_r$ with $r$ on $l$ can occur. For the row with $p=r$, the column entry is the indicator of $t=l$. For any other row, $r$ and $p$ are distinct points on $l$, so the unique line through both is $l$. Again the entry is exactly the indicator of $t=l$. Every leaf column is therefore constant across the rows of its rectangle.

For any nonempty rectangle let $r$ be the rank of its submatrix after augmenting it with a constant-one column. At a leaf $r=1$. At an OR node the two nonempty child rectangles partition the rows. The augmented parent matrix is the vertical concatenation of the two augmented child matrices, so its rank is at most the sum of their ranks. At an AND node the two children partition the columns. Their augmented column spans both contain the nonzero all-ones vector on the common row set, so the parent rank is at most the sum of the child ranks minus one. If a child rectangle is empty, the nonempty child equals its parent and no rank increase occurs. Induction gives $r-1$ at most the number of OR nodes in the subtree. The root rank is $|E|$. This gives the claimed lower bound.

A formula is essential to the last induction. Two child subtrees of a circuit can share an OR gate. The sampled negative inputs also admit small circuit separators when additional independent assignments are omitted.

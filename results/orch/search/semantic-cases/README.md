C5 semantic certificate progress snapshot

Each first_<v>.lean is a standalone kernel-checked finite case using decide +kernel. Complete stdout/stderr and per-case metrics accompany the source. Exactly 102 first-OR values are listed in coverage.json. This is a partial progress snapshot: consult metrics.jsonl for completed cases. Cases 0 and 253 reuse previously checked identical proof bodies with theorem names first_zero and first_test respectively; their copied axiom logs retain those original names. All other case source/log pairs are from the exact shown filename. Only standard Lean axioms propext, Classical.choice and Quot.sound occur. These individual cases do not prove the general graph gap; assembly and generic soundness are separate work.

Reproduction: select the repository toolchain on PATH, then run `python results/orch/search/semantic-cases/runner.py --output /tmp/c5-recheck`. The runner derives the repository root and all Lean definitions from this archive; it has no dependency on the original scratch directory. Use `--values 0 253` for a selected subset, `--repo` for an explicit checkout, or `--lake` for an explicit lake executable. All environment variables are inherited normally, with no credential inspection or copying. The default output directory is a new local `rechecked/` directory. The installed project dependencies must already be built.

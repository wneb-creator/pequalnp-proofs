# Small graph total-gate audit

These experiments test two proposed lower bounds for C4-free bipartite edge functions: total gates at least m + tau - 1, and at least m + tau when both formal derivatives at a chosen edge vanish. Here m is the edge count and tau is the minimum vertex-cover size. This does not establish either conjecture in general or settle L-meta-2602.

The six-cycle has m = 6 and tau = 3. Unrestricted binary AND/OR synthesis returned UNSAT for seven gates (7.69 seconds), with an eight-gate SAT positive control (0.59 seconds). With both edge derivative directions constrained false, eight gates were UNSAT (113.71 seconds), with a nine-gate SAT control (22.62 seconds). The two SAT controls were independently evaluated on all 64 assignments and the required derivative traces. Thus these solver runs support the conjectured sharp counts for this small graph only. The earlier 30-second derivative query was UNKNOWN and is retained separately.

The eight-vertex theta graph consists of three internally disjoint length-three paths between two vertices. It has m = 9 and tau = 4. The eleven-gate ordinary query and twelve-gate derivative query on an internal path edge each timed out after 30 seconds. These are UNKNOWN, not evidence of impossibility.

Each gate chooses AND or OR and two distinct earlier wires. Operand order is restricted to a < b, using commutativity. The output is the final gate. There is no fanout, depth, usage, gate-count-per-operation, or star-cover restriction. Function constraints use every edge assignment and every maximal independent set; the program exhaustively checks this boundary covers all small-graph false inputs. Derivative variables obey the posted Boolean recurrence at the two singleton bases. The encoder checks decoded SAT witnesses against all truth assignments independently of the CNF. The circuit-to-CNF interpretation and UNSAT claims have not been proved in Lean, so these are computational research records only.

`manifest.json` records exact source and solver hashes, arguments, full-output hashes and summaries. Both source versions are retained. All generated CNFs, full solver stdout/stderr, and complete Python summary logs are preserved; gzip files retain every original byte. Scripts use the job-local solver path and scratch directory. The current script accepts `--case`, `--mode`, `--seconds`, `--edge`, and optional `--gates`; its earlier version lacks the explicit gate override.

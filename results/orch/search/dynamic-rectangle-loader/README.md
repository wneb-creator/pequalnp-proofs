Dynamic rectangle loader: reviewed computational search support

The baseline source is the reviewed monotone copy search with cache hysteresis and diagnostic bank export. The dynamic extension keeps its original 13 rectangle matrices and appends exact integer matrices from a local whitespace file. It validates the complete proposed file before publication: unique IDs, dimensions at most 21, distinct and correctly target-labelled sample rows, integer coefficients bounded by one million, and the exact positive total. Existing matrix records must remain unchanged. Reload is attempted only at safe DFS/closure-loop points, at most once per second. Per-matrix profile caches preserve their identity. A new strict whole-bank cut is usable only in monotone mode with roots.length = remaining + 1. Matrix samples, weights, totals and used root costs are recorded in full in the terminal trace.

The exact Gray-code maximum routine is mechanically identical to the previously reviewed routine, with a matrix parameter. Tests preserve all 936 original cost comparisons; an empty loader reproduces the original 3,000-visit smoke and byte-identical completed memo. The nonempty test appends five records to one while preserving the existing cache, rejects 12 malformed/removal/changed-prefix files, and reproduces 108 independently audited root costs and six strict cuts. The test unit differs from production only by an explicit final return 0, needed because the harness renames main as a helper. The first test-only attempt omitted that return and failed; the corrected complete compile/run logs are preserved here.

Frozen matrix versions accompany full JSON provenance. V1 contains six independently audited tailored matrices. V2 appends seven symmetry variants of original weights, independently checked over 119 actual slow banks; V3 appends thirteen further independently audited symmetry variants. These are exact finite computational cuts, not a claim that all their individual kernel certificates have been instantiated. Full-case search traces and later loader versions are archived separately.

Reproduce the finite loader test with g++ -O3 -std=c++17 test_dynamic_loader.cpp -o test_dynamic_loader, then ./test_dynamic_loader dynamic-tests. No network or credentials are needed. The production search can be run with --extra-rectangles pointing to one frozen text version.

# Signed17 terminal certificate measurement

The two earlier completed free-signed17 first-OR computational cases have a joint reachable dependency set of1,453 Live expansion nodes,1,966 formula0 and2,394 formula1 banks. The nonedge run imports completed states from the original edge run; counting only its local1,529 formula leaves omits those dependencies. Exact full120 Petersen symmetry reduces the joint proof-state census to1,343 expansion states,1,928 formula0 and2,330 formula1 banks. This symmetry census is a measurement, not a constructed acyclic Lean proof DAG.

A bounded180-second replay of the reviewed finite signed closure oracle processed1,046 of4,258 representative terminal banks. It completed18,379 tables,2,040,039 derived entries and167,719,444 candidate operations. Its explicit time limit returns exit5; the last formula1 bank may still have unprocessed copied children. The emitted partial certificate-volume stream is12,193,843 bytes, compressed by zlib to4,219,988 bytes. Every recorded table was recomputed closed. This is neither a lower bound on the best possible encoding nor an extrapolation to the full case. It does not prove the theorem, and the encoded data has no Lean decoder/checker here.

The measured stream uses unsigned LEB128. Per table it stores number of roots, number of derived entries, then(op,left-entry-index,right-entry-index) per derived entry; support masks and truth words are derived from that provenance. It then stores the sorted list of distinct rejecting row pairs, encoded(positive-row<<10)|negative-row. Table order and associated raw banks/copy-parent indices are in formula-census.jsonl and formula-banks.txt. The original binary is losslessly preserved as formula-tables-shortlist.zlib, with decompressed hash in formula-census-summary.json. Truth dictionaries and all complete diagnostics/status are preserved.

Reproduce the finite census by decompressing formula-banks.txt.gz, compiling signed17_formula_census.cpp with g++ -O2 -std=c++17, and invoking the binary with INPUT OUTPUT SECONDS. It includes signed17_formula_measured.cpp, a narrowly instrumented copy of the previously reviewed live_search_resume.cpp; instrumentation.patch records every change. No global search or cofactor pruning is invoked by this harness. The terminal census uses all four normalized signed operations and exact target-positive/target-negative separation after the cheap sampled-row filter. Instrumentation records counts and witnesses without changing closure decisions.

The joint/symmetry scripts use original scratch paths for the three full Live traces. Their exact hashes are bound in summary.json; those complete traces are preserved in the sibling signed17-or-edge and signed17-or-nonedge archives. Paths need adapting for replay. The full independent earlier computational audits remain separate from this source-size measurement.

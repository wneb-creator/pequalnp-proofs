# Completed exact-five P4 impossibility

`ReductionsBridgeChunks.lean` and `ReductionsNoFive.lean` compile successfully with Lean4.36.0. The final theorem `PEqualNP.Outside.Pilot64Bridge.noFiveDistinct` excludes every typed circuit with exactly five binary AND/OR gates on four inputs, distinct earlier operands at each gate, and output wire8, if it computes `uv ∨ uA ∨ vD` on all16 assignments and both formal central-edge derivatives vanish. Operand order is arbitrary: a checked normalization theorem sorts it without changing values or derivative traces.

The 2537-clause bridge is fully proved in Lean, in26 chunks. Each clause is satisfied by the explicit assignment generated from a candidate. The final concatenation is definitionally the same concrete formula excluded by the previously checked LRAT replay. The direct evaluator and derivative recurrence are connected to that assignment by separately checked semantic equalities. The final axiom audit for the encoding contradiction, ordered theorem, and arbitrary-order distinct theorem lists only `propext`, `Classical.choice`, and `Quot.sound`. No native evaluation axiom is used.

This is a finite local control, **not a proof of L-meta-2602 or the eight-input double-star bound**. The exact-five theorem uses a typed candidate representation; a general actual-Circuit extraction/prefix/padding transport theorem has not been formalized. Consequently, no formal statement about all circuits with at most five gates is claimed. The separately checked actual six-gate witness is archived under p4_six_witness. These helper namespaces, multiple research imports, large explicit certificate/encoding sources, and diagnostic #check commands are research artifacts, not an Outside proof PR file.

The first chunked attempt failed only while assembling its final empty-list tails and append conjunction. Its complete output is preserved. The corrected proof supplies those tails with `by simp` and normalizes conjunctions with `and_assoc`; its full successful output is preserved, including linter warnings. The monolithic attempt was terminated after that shared tail bug was found; its complete output and termination metadata are retained and no success is claimed from it. Earlier pending/recovery snapshots remain historical snapshots, superseded by this completed result.

Reproduction order is Reductions, ReductionsIR, ReductionsSemantics, ReductionsNormalizeFast, ReductionsBridgeChunks, ReductionsNoFive. Compile the research sources into the job scratch directory using the job Lean4.36.0 toolchain through `lake env` in the repo lean directory, with scratch prepended to LEAN_PATH and `--root` set to the source directory. The preserved generation scripts use the exact job scratch inputs and the archived repair_nearmiss_v3.CNF helper. `p4_bridge_lean.py --count 999999 --split` recreates the original monolithic draft; the chunk generator reads that source and emits the corrected chunked proof. The explicit trace and all generator/dependency hashes are preserved here. The final NoFive composition is ordinary handwritten Lean.

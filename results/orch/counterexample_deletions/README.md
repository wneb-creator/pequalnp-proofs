# Bounded deletion search around masked one-NOT seeds

The search found no exact 24-gate circuit. It enumerated 1,324,800 circuits in 38.115 seconds, starting from 72 independently validated 27-gate one-NOT masked-input circuits. For each seed it chose three gates excluding the output and NOT gate, then replaced each removed output by either of that gate's two inputs. Removal and renumbering occur from later gates to earlier gates, preserving valid dependencies.

Of those candidates, 1,061,015 retained a NOT gate in the output cone. Every such candidate was evaluated on all 16,384 Boolean inputs using complete bit-vector truth tables. The best full-table result has 126 mismatches. Separately ranking the same candidates on the 571 official sample rows gives a best score of two sampled mismatches and 206 full-table mismatches. Both are approximate phase seeds, not counterexamples. The census describes this finite heuristic family only and proves nothing about other circuits.

All 72 input seed JSONs, the original index, exact search/evaluation sources, complete stdout/stderr, exact result metadata, and best candidates are retained. To reproduce, restore `seed-index.json` as `/tmp/oec/pequalnp-pilot-85/abc-search/masked-seeds/index.json`, restore the `seeds/` files in that same scratch directory, and restore the search/evaluation files under `/tmp/oec/pequalnp-pilot-85/counterexample/`. The index contains positive-mask records too; the program filters them out before reading any seed, so those unused positive seed files are unnecessary. Run `python3 delete_masked.py` and preserve its complete output.

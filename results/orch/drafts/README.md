# Preserved authoring drafts

These text snapshots preserve earlier authoring work, not additional verified
proofs. Most were superseded by the named7090-line partial, the complete q3
word-certificate artifact, or the q5 geometry artifact. The exact compile
status of each snapshot is not asserted. In particular direct_matrix_circuit
is unverified. No file here is a submitted proof or a counterexample.

The manifest records original names, full hashes and line counts. Copies
were byte-verified before removing the redundant untracked working copies.

Shared-width feasibility
WidthPrototype.lean is a checked741-line,39758-byte generalization of the Live1024Count prefix before concrete input tables. It uses Sig=BitVec(width+1), Row=Fin(width+1), explicit width parameters where inference requires them, and two explicit Fin index-bound facts. Live extraction, normalization, Reach/Run contraction, row tables and list_run all compile for arbitrary positive widths.
Independent review mechanically reversed these changes to the original prefix, modulo whitespace; review-width-prototype.txt records PASS.

The two original512/1024 prefixes total about67KB. Keeping compatibility aliases for all114 names costs approximately10–14KB, so the current generalized prefix saves only14–17KB. A smaller public alias surface can improve this. Later generic checker/lower-bound sections offer roughly another10–15KB of duplicate source before parameter/alias overhead. These savings overlap with dependency pruning, particularly the old nine-variable circuit extraction; they must not simply be added twice. A realistic combined helper budget remains roughly290–310KB, depending on how aggressively compatibility names are removed. No large rewrite has been started.

# L-meta-2448: ownership routes

The new target minimizes total `Circuit.size`, not OR count, and computes the exact graph edge function on every Boolean input. The old L-meta-1896 controls do not meet this target's hypotheses.

`Owns n C j u v` requires an AND gate j true on the two-vertex input and every earlier AND in j's strict dependency cone false on that input. Its definition is independent of the graph. Invalid or forward reads return false and contribute no cone membership. `HasStarProfile` explicitly permits an empty owned-edge family, including at n=0. These boundary cases reveal no immediate counterexample.

For a triangle-free graph, an arbitrary pairwise-intersecting family of edges has a common endpoint. Consequently `HasStarProfile` is equivalent to every pair of edges owned by one gate sharing an endpoint. A failure has a concrete witness: one AND gate owning two vertex-disjoint graph edges. `OwnershipCombinatorics.lean` extracts this elementary argument from the internal common-center proof in the repository's R_meta_1031_1 reduction. It needs no circuit minimality, monotonicity or C4 assumption. It compiled on the first run with exit 0 in 3.51 seconds; the immutable source, complete log and status are under `checked/OwnershipCombinatorics.*`, SHA256 8fadf5bcd41aa843fc1e0a687efc6f7c6897ab036fcd4ff48f0dc6e8e949bd8c. Four deprecation notices concern the old spelling of the negation-pushing tactic; there were no errors.

The accepted L_meta_1600 theorem supplies a different useful criterion: an AND gate whose truth implies the exact graph function has star ownership in a C4-free graph. Inspection shows that its proof uses soundness only on pairInput s t. Thus it can be strengthened to require only rejection of nonedge pairs and singleton inputs. In particular, a nonstar owner must have a false positive of weight at most two; a high-degree witness is unnecessary. This strengthening has been communicated to the normalization/exchange agents, but is not yet asserted as a new checked theorem here.

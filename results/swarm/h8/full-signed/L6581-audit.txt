The H9 prefix totals 253305 bytes. This is a useful compact base, but it
omits the 279 augmented-root monotone columns used by L670. Reuse for a
monotone closure requires either retaining those prerequisites or rerunning
with the plain signed columns and the monotone factor cuts.

Encoding caveat: decodeBank/readNode use four-bit operand indices and
ten bits per stored gate. Native paths longer than six or seven prefix
gates can refer beyond bank index 15. Such paths require reconstruction
with fewer gates or a five-bit operand/twelve-bit gate encoding update.
The existing hash indexes recheck actual signal-set equality, so hash
fingerprints are accelerators rather than trusted identities.

This directory contains an exploratory native search for monotone Petersen circuits with at most 19 binary gates. It is not a Lean proof or a certificate accepted by the project checker.

The target uses the exact ten-variable Petersen edge function. The root contains all ten input functions. A state consists of distinct nonconstant Boolean functions and a remaining gate budget. Each transition chooses two distinct functions, AND or OR, and either keeps or consumes each operand. It rejects existing/constant results, excess live width, failure to separate any of the 225 positive-edge/maximal-independent pairs, and checked cofactor projection inequalities. Symmetries are the 120 independently verified graph automorphisms. When the remaining budget is at most state width, the search uses the generic kwCross and oneShare Horn/parity obstructions from L_meta_670; these require Lean replay before any proof claim.

Projection pools embed all 434 distinct moC/sgC columns from L_meta_670 into each of the ten vertex-zero cofactors. Each embedding transports both the domain and any augmented input function. Ten additional pools use the full H9 monotone lower bound 16. Exact duplicate domain/root pools retain the larger lower bound, producing 2,997 pools. Signed lower bounds may be weakened to monotone bounds, but the current data must not be used for a signed search.

Binary trace files use little-endian integers:

- pools.bin: uint32 count, then each pool has 128 bytes of truth-table domain, uint32 bound, uint32 root-count, then that many 128-byte masked root tables.
- wires.bin: records of 128 truth-table bytes followed by four int32 values (operation, left wire ID, right wire ID, input-variable index). Operation -1 marks an input or a table without a recorded expression; variable index >=0 marks an original input. A word's bit r is its value on assignment r.
- frontier-N.bin: uint64 number of recorded wires, uint64 number of states; each state has uint32 live-width, uint32 prefix-length, live-width uint32 wire IDs, and prefix-length triples of int32 (operation,leftID,rightID). The remaining budget is 19-N. Wire IDs refer to the prefix of wires.bin named in the header.
- factor-states.bin: repeated uint32 budget, uint32 width, then width uint32 wire IDs. These are states pruned by the generic factor test.

Complete compiler/search stdout and stderr are retained alongside the trace. The search-trace run is the retained run; earlier search and search-fast runs were stopped after replacing them with the same deterministic search plus trace recording. Independent scalar checks of projection data and both known 20-gate constructions are in audit/.

Portable reproduction: run fullprobe_data.py --repo <checkout> --output <scratch>; compile fullprobe.cpp with g++ -O3 -march=native -std=c++20 -I <scratch>; run the resulting executable with explicit working directory <scratch>. Arguments are maximum depth, all-paid-prefix toggle, factor-cut toggle (recommended 19 1 1). The optional data-generator --augmented flag adds 30 conditional nativeH9 pools, recorded in metadata.json; those additional bounds have not been checked by Lean.

Optional executable arguments4and5 resume from a retained frontier: <maximum-depth> <all-paid> <factor> <resume-level> <source-directory>. Run from a DIFFERENT output directory containing identical pools.bin; the source directory must contain frontier-N.bin and its matching wires.bin. The resumer verifies wireIDs and reconstructs the same stored original prefixes.
